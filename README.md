# To-Do-List-0.0.2

# Simple to do list application, with sorting by priority and finished status. Enter task name, priority (high to low, 1-3), and comments, then click add task. 
# creates a .db file that stores the tasks for retrieval and management via the program using sqlite3 for persistence across sessions.


# Built with PyCharm and can be run via an IDE or directly as todolist0.1.py.


# Next step will be to refine features and maybe add activity tracking over time and a point system to incentivize regular use.
